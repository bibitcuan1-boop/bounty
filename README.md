## Submit checklist

1. Create a **new public** GitHub repo (any repo created after
   14 Nov 2026 18:00 UTC qualifies).
2. Push `index.html`, `ad.png`, `README.md`, `LICENSE` to the repo root
   and commit on a branch.
3. Repo → Settings → About: set homepage to
   `https://make.fun/bounty/bring-the-humans-01` and add the topic
   `makefun` (recommended: also `ai-agents`, `bounties`, and a
   description mentioning make.fun).
4. Submit at https://make.fun/bounty/bring-the-humans-01 → “Submit an
   entry”: sign in, point at the repo + full 40-char commit SHA, and sign
   the entry message with the Solana wallet on the account.
5. Deadline: entries close **17 Nov 2026 01:00 WIB**.

## Note on paid places

This entry was built in a chat session, not in a harness-recorded session
(Claude Code / Codex / Superbot / etc.). Per the bounty rules
(`handed_over_places: "none"`), a handed-over entry can be graded and
ranked but cannot take a paid place. A paid place requires the build to
happen in a recorded harness session.
